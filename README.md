# TraceSafe

거래 서명 전에 복잡한 암호화폐 트랜잭션을 사람이 읽을 수 있는 설명과 위험 신호로 바꿔주는 웹 MVP입니다.

## 문제

지갑에서 디앱 거래를 승인할 때 `approve`나 `setApprovalForAll` 같은 함수가 그대로 표시되면, 사용자는 어떤 권한을 넘기는지 알기 어렵습니다. TraceSafe는 서명 전에 자산 이동과 권한 범위를 확인하도록 돕습니다.

## 현재 구현된 기능

- 트랜잭션 해시 입력 및 샘플 거래 분석
- `approve`, `setApprovalForAll`, 일반 ETH 전송 시나리오 해석
- 높음·주의·낮음 위험도 표시
- 자산 이동, 권한 부여, 주의사항을 자연어로 설명
- 예상 네트워크 비용 표시
- 읽기 전용 분석 흐름
- 모바일 반응형 UI
- Sepolia 공개 RPC를 이용한 실제 트랜잭션 해시 조회
- ETH 전송과 기본 `approve`·`setApprovalForAll` 함수 자동 감지
- 가스비·잔액·pending 상태를 확인하는 거래 가능성 사전 점검

샘플 거래는 발표와 UX 검증에 사용되며, 66자리 Sepolia 트랜잭션 해시를 입력하면 공개 RPC에서 실제 거래를 읽기 전용으로 조회합니다. 거래 전송이나 지갑 서명은 수행하지 않습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소를 엽니다.

프로덕션 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
npm run build
```

## 다음 개발 단계

1. Etherscan 또는 RPC API로 실제 트랜잭션 조회
2. ABI 기반 함수·토큰 권한 자동 해석
3. 컨트랙트 주소와 토큰 승인 위험 신호 수집
4. 지갑 연결 및 실제 거래 전 서명 시뮬레이션
5. 사용자 테스트와 분석 정확도 평가

## 주의

TraceSafe의 분석 결과는 참고용이며 거래의 안전을 보장하거나 투자 조언을 제공하지 않습니다. 현재 버전은 실제 거래를 전송하지 않습니다.
